Code signing policy

Windows release binaries of MedExpand are built by GitHub Actions from this public repository and signed via SignPath.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Roles
Committers, reviewers and approvers: @bigonroad
Privacy

MedExpand makes no network connections and does not transmit anything you type. Snippets and statistics are stored in plain-text files next to the executable.
